# 把妹聊天模拟器（V2.3）

一个装在你电脑上的小工具，让你在安全、没有真实后果的环境里练习和异性聊天。和你对话的是 AI 扮演的角色，聊得好聊得坏都不会影响现实。

## 它能做什么

- **认识一个人**：你可以简单描述想认识什么样的人，或者让它随机生成一个。每个人物都有名字、年龄、城市、工作、性格、喜好，也有自己的边界。
- **和她聊天**：像发微信一样一句一句聊。她会按自己的性格回应你——可能热情，也可能客气、冷淡，甚至结束对话。
- **聊完复盘**：聊到一段落，点「结束聊天并复盘」，它会告诉你哪里做得好、哪里可以改进，并给出下次可以怎么说的具体建议。
- **记住你们的事**：它会记住重要的信息（聊过什么、对方的偏好、关系进展），下次接着聊还记得。

## 为什么做这个小工具

现实里和人相处，试错成本很高，说错一句话可能就没有下文了。这个小工具想给你一个放心练手的地方。

而且它刻意**不做成「教套路」的工具**，更想让你练习真诚、平等、尊重对方的边界。所以这里的人物不会因为你说了漂亮话就立刻心动——她们有自己的生活和节奏，也可能拒绝你。

## 怎么用

1. **准备一把钥匙**：这个工具靠 DeepSeek 的 AI 服务生成人物和回复，需要你自己的 DeepSeek API Key。第一次打开时，把它填在左侧边栏并保存。以后就不用再填了（它会记在你电脑的 Windows 凭据管理器里）。
2. **启动**：双击文件夹里的 `打开把妹聊天模拟器.bat`。第一次启动会自动安装所需的东西，可能要等几分钟；之后会快一些。装好后它会自动在浏览器里打开界面。
3. **开始聊天**：在首页描述一个你想认识的人（或点「随机认识一个人」），生成角色后进入聊天页，像平时打字一样说话就行。
4. **聊完复盘**：点「结束聊天并复盘」，看看反馈，把建议带到下一次。
5. **不想聊了**：可以「结束这段关系」或「归档人物」，历史记录都会保留，随时能回来翻看。

想不起来聊什么时，聊天页有个「让 AI 帮我找话题」的按钮，会给你一个方向（每次会扣一点好感度，每天有次数上限）。

## 关于隐私和花费

- 你的对话记录和人物档案只存在你自己的电脑上，不会上传到任何地方。
- API Key 保存在 Windows 的「凭据管理器」里，不会写进项目文件。
- 侧边栏会显示你用了多少、大概花了多少钱，超过每月预算会提醒你。

## 给想改代码的人

- 运行环境：Windows、Python 3.10 或以上。
- 跑测试：`.venv\Scripts\python.exe -m pytest -q`
- 想改模型、超时、价格、月度预算、话题每日上限等设置：编辑 `config.py`。
- 人物数据保存在 `data/girls/`，用量记录在 `data/usage.json`。
- 自己的私人笔记可以放在 `personal notes/` 文件夹里，它已在 `.gitignore` 中被整体忽略，不会被提交或上传。
