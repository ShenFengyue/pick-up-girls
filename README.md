# 把妹聊天模拟器（V2.2）

一个运行在本机的 Streamlit 社交练习工具。人物由 DeepSeek 生成，聊天、关系记忆和复盘保存在本地；模拟中的人物保持自主性，允许分歧、冷场、拒绝和关系结束。

## 环境要求

- Python 3.11 或更高版本
- DeepSeek API Key（创建角色、聊天、话题建议和复盘需要）

## Windows 启动

双击项目目录里的 `打开把妹聊天模拟器.bat`。它会只在本机启动 Streamlit 服务并自动打开浏览器；关闭启动时出现的命令窗口即可停止应用。项目依赖已安装在本地 `.venv`，不需要每次重复安装。如果 `.venv` 不存在，启动器会自动寻找 Python 3.10 或更高版本、创建环境并安装依赖（首次运行需要网络）。

首次使用时，在应用侧边栏输入 DeepSeek API Key 并保存。密钥会记在当前 Windows 账户的 Windows 凭据管理器中，之后打开应用无需重输；可以在侧栏更换或删除。若希望临时复用 Windows `DEEPSEEK_API_KEY` 环境变量（例如 Codex 使用的变量），需明确勾选；应用不会自动导入该变量。

## 数据与隐私

每个人物单独保存在 `data/girls/<自动编号>.json`，UTF-8 编码并通过临时文件原子替换更新。聊天历史完整保存在本地；请求模型时只发送近期对话和精简长期记忆。AI API Key 不写入人物档案。`data/girls/*.json` 默认被 Git 忽略。

模型调用用量记录在 `data/usage.json`（同样默认被 Git 忽略），用于本地统计 token 与估算费用，不包含聊天内容。

JSON 文件可以复制备份。删除人物文件会永久删除对应本地资料；归档或结束关系则会保留全部历史。

## 使用说明

- 首页支持按简短描述创建，或随机认识一位成年女性。
- 聊天页面恢复历史消息；请求话题固定扣 1 点好感度，失败也不退还。
- 结束聊天后可复盘本次互动，好感度调整限制在 -2 到 +2，并记录具体依据。
- 长期记忆按「事实、偏好、关系节点」三类累积保存，每次复盘增量合并，而不是被覆盖。
- 侧边栏显示本次会话与本月的 token 用量和估算费用，超过月度预算会提醒；「让 AI 找话题」有每日次数上限。
- 模型、温度、超时、定价、月度预算与每日上限都集中在 `config.py`，按需调整即可。
- 好感度归零时关系进入结束状态，历史档案仍可查看。
- 人物档案页提供完整档案、长期记忆、聊天历史、复盘和关系变化记录。归档与关系结束是分开的状态。
